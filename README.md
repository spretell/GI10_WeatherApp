Hi! This project is a full-stack weather application built with node and express. It allows users to search for current weather conditions using either a city name or a U.S. zip code, with support for both imperial and metric units.

☁︎ about this project

This weather app was created as part of my web development coursework and learning journey into backend development. The goal of this project was to better understand how servers, apis, and frontend interfaces communicate with each other.

Instead of calling weather apis directly from the browser, this project uses a custom express server to handle requests, process data, and return clean responses to the frontend.
